# Leticia Talks Law

Single-page educational website for **Leticia Talks Law — Women & the Law**.

## Files

- index.html — complete one-page website
- style.css — responsive visual design

The site is dependency-light and can be deployed as a static site on Vercel, Netlify, GitHub Pages, or another static host.

## Important

The website contains general legal information about Alberta's Dower Act and includes a legal-information disclaimer. It is not a substitute for legal advice.
